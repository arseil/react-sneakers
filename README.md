## ✨ Возможности

- **Каталог товаров** — загрузка кроссовок из базы данных Supabase.
- **Поиск** — фильтрация каталога по названию товара.
- **Корзина** — добавление товаров, в том числе нескольких экземпляров одного товара, и удаление отдельных записей.
- **Расчёт стоимости** — автоматический подсчёт суммы товаров и налога 5%.
- **Избранное** — добавление и удаление товаров с сохранением состояния в Supabase.
- **Обратная связь** — состояния загрузки, обработка ошибок и уведомления об ошибках.
- **Адаптивный интерфейс** — стили компонентов на SCSS Modules.

> Кнопка оформления заказа пока демонстрационная: реальная покупка и обработка платежей не реализованы.

## 🚀 Запуск проекта

### 1. Установите зависимости

```bash
npm install
```

### 2. Настройте переменные окружения

В корне проекта создайте файл `.env.local` и добавьте данные своего проекта Supabase:

```env
REACT_APP_SUPABASE_URL=your_supabase_project_url
REACT_APP_SUPABASE_PUBLISHABLE_KEY=your_supabase_publishable_key
```

Значения можно найти в настройках подключения проекта Supabase. Используйте именно **Publishable key**. Не добавляйте в React-приложение секретный `service_role` key.

Файл `.env.local` исключён из Git через `.gitignore`. После изменения переменных окружения перезапустите dev-сервер.

### 3. Запустите приложение

```bash
npm start
```

Приложение откроется по адресу [http://localhost:3000](http://localhost:3000).

## 🗄️ Supabase

Supabase используется как backend и база данных PostgreSQL. Для работы приложения созданы три таблицы в схеме `public`.

### Структура таблиц

**`items` — каталог товаров**

| Поле | Назначение |
| --- | --- |
| `id` | Уникальный идентификатор товара |
| `title` | Название |
| `price` | Цена |
| `imageUrl` | Путь к изображению в папке `public` |

**`cart` — корзина**

| Поле | Назначение |
| --- | --- |
| `id` | Уникальный идентификатор записи корзины |
| `title` | Название товара |
| `price` | Цена на момент добавления |
| `imageUrl` | Путь к изображению |
| `productId` | ID исходного товара из `items` |
| `created_at` | Дата создания записи |

Каждое добавление создаёт отдельную запись, поэтому один товар можно добавить несколько раз и удалять экземпляры независимо.

**`favorites` — избранное**

| Поле | Назначение |
| --- | --- |
| `id` | Уникальный идентификатор записи |
| `productId` | ID товара из `items` |
| `created_at` | Дата добавления в избранное |

Для `productId` настроено ограничение уникальности: один товар не может дублироваться в избранном. Связь с `items` настроена с удалением зависимой записи при удалении товара из каталога.

### Доступ и ограничения демонстрационной версии

- Каталог доступен для публичного чтения.
- Корзина и избранное доступны через публичные операции чтения, добавления и удаления.
- Row Level Security (RLS) включён для таблиц.
- Авторизация пользователей не реализована.

**Важно:** поскольку авторизации нет, корзина и избранное общие для всех посетителей сайта. Любой посетитель может видеть и изменять эти данные. Такая схема используется только для демонстрационного проекта и не подходит для персональных корзин или пользовательских данных в production-приложении.

Publishable key предназначен для использования на клиенте. Безопасность доступа обеспечивается политиками RLS; секретный ключ Supabase нельзя помещать во frontend-код.

## 🛠️ Технологии и подходы

- **React** — функциональные компоненты и React Hooks.
- **Custom Hooks** — вынесение логики загрузки данных и управления состоянием из компонентов.
- **Supabase JavaScript Client** — взаимодействие с PostgreSQL через Data API.
- **PostgreSQL** — хранение каталога, корзины и избранного.
- **Row Level Security (RLS)** — настройка публичного доступа к таблицам.
- **SCSS Modules** — изолированные стили компонентов.
